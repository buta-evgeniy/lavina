# Журнал разработки проекта «Лавина»

## 2026-11-03 - Большое обновление: универсальная версия

### Что сделано
1. Собрано приложение с нуля как единый файл `app/index.html` (React 18 + Tailwind + Lucide, стиль Japandi).
2. Онбординг и настройки (шестеренка): доход, лимит на месяц, обязательные платежи,
   накопления, карты (динамический список), кредиты со ставками, ставка ЦБ.
   Жестко зашитых цифр больше нет - приложение универсально для любого пользователя.
3. Главный экран: кольцо дневного лимита со «светофором», кнопка «День 0 ₽»,
   лента трат, 12 категорий, выбор источника списания (карта / накопления / наличные),
   режим возврата денег.
4. Аналитика: доли по категориям с подсветкой >20% лимита, предупреждение по
   импульсивным тратам, листание по месяцам, режим «Год».
5. Мои Финансовые Цели: 3 горизонта, добавление целей с дедлайнами, галочки.
6. Умная плашка по скорости трат (на сколько дней хватит лимита).
7. Вердикт фин-советника, блок «Что делаем завтра?», ачивки (4 медали).
8. Умный советник AI (Макро): рефинансирование, три кубышки 10/40/50,
   вклады и инвестиции от ставки ЦБ.
9. AI-Весы: калькулятор нового кредита (аннуитет, ИДН, безопасность 0-100%).
10. Таймлайн «Лавина»: универсальный, фазы добавляются вручную или из шаблона.

### Технические решения
- JSX компилируется Babel в классическом режиме (runtime: classic) через
  bootstrap-скрипт: Babel 8 по умолчанию выдает ES-модули, которые не работают
  в обычном script-теге (причина «белого экрана» при первой версии).
- Данные: localStorage (lavina_profile, lavina_expenses, lavina_zeroday,
  lavina_goals, lavina_phases).
- Миграция старого профиля (sber/alfa поля) в динамический список карт -
  функция migrateProfile.
- `app/server.js` - статический сервер без зависимостей для `npm run dev`.

### Как запускать
- Двойной клик по `app/index.html` (нужен интернет для CDN)
- или `cd app && npm run dev` → http://localhost:7100/
