# Лавина

Приложение по финансовой грамотности для покупателей.

## О проекте

«Лавина» - приложение, которое помогает покупателям разбираться в финансах:
осознанно планировать покупки, понимать кредиты, рассрочки и личный бюджет.

## Структура проекта

- `docs/` - описание проекта, требования, исследования
- `app/` - исходный код приложения
- `assets/` - картинки, иконки, логотипы
- `data/` - данные приложения
- `tests/` - тесты
