# Лавина - персональный финансовый трекер

Интерактивное одностраничное приложение (dashboard) для ежедневного контроля трат,
долговой стратегии и финансовых целей. Стиль: скандинавский минимализм (Japandi).

## Быстрый запуск

### Способ 1: просто открыть файл
Дважды кликните по файлу `app/index.html` - приложение откроется в браузере.
Нужен интернет (React, Tailwind и иконки подгружаются из CDN).

### Способ 2: локальный сервер
```
cd app
npm run dev
```
Откройте http://localhost:7100/
Аргументы `--port` и `--host` поддерживаются: `npm run dev -- --port 8080`.

### Онлайн-версия (GitHub Pages)
После включения Pages (ветка main, корень) приложение доступно по адресу:
https://buta-evgeniy.github.io/lavina/app/

## Важно про данные

- Все данные (профиль, траты, цели, фазы) хранятся локально в браузере (localStorage),
  на устройстве пользователя. Никуда не отправляются.
- Полный сброс: шестеренка (Настройки) - кнопка «Сбросить все данные приложения».
- Приложение универсально: жестко зашитых цифр нет, все параметры вводятся
  при первом запуске (онбординг) или через шестеренку в шапке.

## Карта блоков приложения

| Блок | Что делает |
| --- | --- |
| Вердикт фин-советника | Живая плашка в шапке: похвала / предупреждение по тратам дня |
| Умный совет по скорости трат | Считает, на сколько дней хватит месячного лимита при текущем темпе |
| Дневной лимит (кольцо) | Светофор: зеленый / желтый (< 700 ₽) / красный (минус или «День 0 ₽») |
| Добавить трату | 12 категорий, выбор источника списания (карта / накопления / наличные), режим возврата, кнопка «День 0 ₽» |
| Что делаем завтра? | План на завтра по итогам сегодняшнего дня |
| Траты сегодня | Лента трат дня с источником и удалением |
| Аналитика | Доли по категориям с подсветкой >20% лимита, предупреждение по импульсивным тратам, листание по месяцам, режим «Год» (по месяцам и категориям) |
| Мои Финансовые Цели | 3 горизонта (1 месяц / 3 месяца / 1 год), добавление целей с дедлайном, галочки выполнения |
| Тактический контроль | Карточки всех карт (долг/лимит/статус), накопления, кэш в кубышке |
| Мои Ачивки | Медали за дисциплину: Стальной Огурец, Финансовый Хирург, Гроза КБ, Защитник Гранаты |
| Умный советник AI (Макро) | Рефинансирование (ставка ЦБ + 3% vs ставки кредитов), правило трех кубышек (10/40/50), советы по вкладам и инвестициям |
| AI-Весы | Симулятор «брать ли кредит»: аннуитетный платеж, индекс долговой нагрузки, шкала безопасности 0-100% |
| Таймлайн «Лавина» | Долгосрочная дорожная карта: фазы добавляются вручную или из шаблона, разворачиваются, отмечаются выполненными |

## Настройки (шестеренка)

Доход, лимит на жизнь, обязательные платежи, накопления, список карт
(неограниченно: название, долг, лимит, статус), список кредитов со ставками
(для анализа рефинансирования), ключевая ставка ЦБ.

## Категории трат

Авто, Продукты, Медицина, Косметика, Связь, Налоги, Детям, ЖКХ, Подарки,
Транспорт, Импульсивно, Другое.

## Технологии

Один файл `app/index.html`: React 18 + Tailwind CSS + Lucide (через CDN),
JSX компилируется Babel в классическом режиме в момент загрузки.
`app/server.js` - минимальный статический сервер без зависимостей (Node.js).
